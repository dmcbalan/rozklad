# Розклад занять

https://balanstudy.com.ua/rozklad/

**Для учнів.** Тижневий розклад, який оновлюється наживо. Можна шукати себе за ім'ям, переглядати вільні вікна й залишати заявку на заняття. Розклад можна переглянути в будь-якому часовому поясі (кнопка 🌍, пошук за містом, країною чи GMT+N); заняття ведуться за київським часом. Є кабінет учня за посиланням `?s=код` з вкладками: огляд (скільки уроків лишилось, наступне заняття, кнопка Meet), чат з викладачем, заняття на 4 тижні та історія, домашні завдання, мої роботи (фото). Сайт можна встановити на телефон як застосунок (PWA).

**Для викладача (вхід через Google).**
- Редагування постійного розкладу.
- Разові зміни на конкретну дату: перенос (відпрацювання, якщо не можеш ти, або перенос на прохання учня), додаткове заняття, скасування.
- Відмітки: Був / Пропустив / Перенесено, кілька уроків на день.
- Абонементи: 1 урок за 350 ₴, 10 уроків за 3500 ₴, 20 уроків за 6500 ₴. Ціни задаються в `PACKS` у `app.js`.
- Статистика: дохід, проведені уроки, відпрацювання, додаткові, пропуски, переноси.
- Заявки з вільних вікон.
- Чати з учнями (вкладка «Чати», з лічильником непрочитаних).
- Перевірка ДЗ (вкладка «ДЗ»): учень надсилає текст, посилання або файл до 650 КБ, викладач зараховує або повертає на доопрацювання з коментарем.
- Медалі (кнопка «🏅 Медалі» в картці учня): понад 30 медалей у розділах Курси / Навички / Характер / Особливі + автоматичні. Каталог — `MEDALS` у `app.js`.
- Сертифікати (кнопка «🎓 Сертифікат»): обираєш курс, і сертифікат створюється сам, учень може завантажити PNG. Список курсів — `COURSES`.

**Ігрові механіки для учня.** Рівні й XP (урок +10, зараховане ДЗ +15, медаль +5, бонуси колеса), колесо фортуни раз на тиждень (якщо за 7 днів був урок; призи — `PRIZES`), персонаж, речі для якого відкриваються з рівнями.

**Сповіщення.** Дзвіночок у шапці: нове ДЗ, медаль, перевірка ДЗ, сертифікат, повідомлення в чаті (у викладача — нові повідомлення, ДЗ, заявки, колесо). Системні сповіщення працюють, поки сайт відкритий або згорнутий; щоб вони приходили на закритий застосунок, потрібен сервер для push.

**Телефон.** Нижнє меню: в учня — Розклад / Чат / Профіль / Налаштування, у викладача — Розклад / Відмітки / Учні / Чати / Ще.

## Firebase

Проєкт `rozklad-zanyat-fe37b`. Після кожної зміни `firestore.rules` скопіюй файл у **Firestore → Rules** і натисни **Publish**.
Домен сайту має бути в **Authentication → Settings → Authorized domains**.

Перевірка локально: `npx serve .`
